# رحلة الإنجليزي: المرحلة الأولى A2 → B1

تطبيق واحد فيه كل محاور الإنجليزي: القواعد، النطق، الكلمات، الاستماع، القراءة، الكلام، الكتابة، والخطة والتقدم.
بيشتغل من غير نت بعد أول فتحة، وكل بياناتك محفوظة على موبايلك بس.

## النشر على Vercel (مرة واحدة)
الكود موجود في فولدر `english-journey/` جوه ريبو `TARGET-PRO`، فلازم تقول لـ Vercel يبص على الفولدر ده بس.

1. ادخل https://vercel.com/new وسجّل بحساب GitHub.
2. اختار ريبو **TARGET-PRO** ← Import.
3. في **Root Directory** دوس Edit واختار `english-journey`.
4. **Framework Preset**: Other. سيب Build Command و Output Directory فاضيين.
5. Deploy. هتاخد رابط زي `https://english-journey-xxxx.vercel.app`.

بعد كده أي تعديل يترفع على الفرع الأساسي (main) بيتنشر لوحده في دقيقة.

> لو الكود لسه على فرع غير `main`، يا إما تعمل merge الأول، يا إما من Vercel: Settings ← Git ← Production Branch واكتب اسم الفرع.

## تركّبه على الموبايل
1. افتح رابط Vercel من الموبايل.
2. أندرويد (Chrome): القايمة ⋮ ← "إضافة إلى الشاشة الرئيسية" / Install app.
3. آيفون (Safari): زرار المشاركة ← "إضافة إلى الشاشة الرئيسية".

## الملفات
- `index.html` و `app.js`: التطبيق
- `data.js`: المحتوى (الـ 12 أسبوع، الروتين، المصادر، 150 كلمة بداية). تقدر تعدّل فيه.
- `notes/grammar.html` و `notes/pron.html`: مذكرة القواعد ومذكرة النطق
- `sw.js` و `manifest.webmanifest` و `icons/`: ملفات التثبيت والأوفلاين
- `vercel.json`: إعدادات النشر (الكاش وأذونات المايك)
- `PLAN_AR.md`: خطة التحسين وتطوير المحتوى

## مهم
- خد نسخة احتياطية كل أسبوع: ⚙ ← تصدير. التطبيق هيفكّرك في شاشة "النهارده" لو عدّى أسبوع.
  لو مسحت بيانات المتصفح من غير نسخة، التقدم هيروح.
- التحديثات بتوصل لوحدها: التطبيق بيجيب أحدث نسخة من النت لما يكون فيه نت، ومن الكاش لما مفيش.
  لو غيّرت قايمة الملفات نفسها (ضفت أو شيلت ملف)، عدّل `FILES` و غيّر `ej-v2` في `sw.js` لـ `ej-v3`.
- لما تضيف كلمات في `STARTER` جوه `data.js`، ضيفها **في الآخر** بس. ترتيب الكلمات هو اللي بيربطها بتقدمك.
